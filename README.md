## 💎 PIMPJS 💎
An abstracted responsive UI/UX creation automation library based on React.

## 🚀 Features
- 📦 abstraction of typical design patterns in React to create common UI/UX components in a faster and more succinct way.
- ⚡ Fast and lightweight (minimized and compressed)
- 🛠️ Built with OOP principles.

## 🧰 Why use pimpjs?
-  ⏱️ This library allows web developers to design dynamic content and SPA projects in less time.
-  🧠 Once you learn the API, you work faster and more efficiently in UI/UX implementation.
-  💩 Because endless javascript library slop is every web developer's life.
